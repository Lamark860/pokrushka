# База Маркетинг — система органического трафика

Генерирует SEO-статьи и посты в голосе автора под конкретную площадку, вы публикуете их
руками, а система ведёт учёт: что опубликовано, что зашло, сколько подписок и заявок принесло.
Автопостинга нет — публикация копипастом, поэтому риска блокировок аккаунтов нет.

Готовы **этапы 1–4**: генерация под площадку, проверка текста, ключевые слова, кнопки
копирования, трекинг-ссылки со счётчиком переходов, учёт подписок, статистика площадок и
дашборд с воронкой до денег. Сервис развёрнут на сервере — как именно, в `DEPLOY.md`.

## Запуск

```bash
cd ~/projects/traff
cp .env.example .env                 # заполнить SECRET_KEY, BOOTSTRAP_PASSWORD, при желании ANTHROPIC_API_KEY
python3 -m venv .venv && ./.venv/bin/pip install -r requirements-dev.txt

docker compose up -d db              # Postgres на 5436
./.venv/bin/alembic upgrade head     # таблицы
./.venv/bin/python -m app.cli bootstrap   # первый пользователь и проект с контент-ДНК

./.venv/bin/uvicorn app.web.main:app --port 8099 --reload
```

Открыть http://localhost:8099 и войти под `BOOTSTRAP_EMAIL` / `BOOTSTRAP_PASSWORD`.

Всё целиком в контейнерах: `docker compose up` (миграции накатятся сами).

На сервере разворачивается отдельным набором файлов — `docker-compose.prod.yml` и
`.env.prod`, порядок действий в `DEPLOY.md`.

## Рабочий цикл

1. **Проект** — указать каналы (Telegram, MAX, сайт), поправить голос и кейсы, загрузить
   ключевые запросы (вставкой или CSV).
2. **Сгенерировать** — выбрать тему (темник подсказывает), площадку и ключи.
3. **Статья** — прочитать замечания валидатора, скопировать кнопкой под нужную площадку
   (HTML для Дзена и vc.ru, Markdown для Telegram и MAX; у vc.ru подзаголовок копируется
   отдельно) и опубликовать руками.
4. Вставить ссылку на публикацию — к ней будет цепляться статистика.

Ссылки в тексте ведут через наш редирект `/r/<код>` — так считаются переходы. Если это
мешает (например, площадка не любит внешние домены), в настройках проекта выключается
галочка «считать клики», и в текст пойдут прямые ссылки.

## Трекинг подписок

Чтобы система знала, из какой статьи пришёл подписчик, нужен бот:

1. Создать бота у @BotFather, положить токен в `TELEGRAM_BOT_TOKEN`.
2. Добавить бота **администратором канала** с правом приглашать пользователей — без этого
   Telegram не присылает события вступления.
3. Указать ID канала (`-100…`) в настройках проекта.
4. Проверить доступ: `./.venv/bin/python -m app.cli check-bot`.
5. Запустить слушателя (отдельный процесс, должен работать постоянно):

```bash
./.venv/bin/python -m app.bot.listener
```

Дальше каждая новая статья получает собственную пригласительную ссылку, а вступившие по ней
попадают в базу с привязкой к статье. Переходы и подписки видно на странице статьи.

Ключи TGTrack (`TGTRACK_TG_API_KEY`, `TGTRACK_MAX_API_KEY`) нужны для MAX и для добора
меток по тем, кто пришёл мимо ссылок: `./.venv/bin/python -m app.cli tgtrack-sync`.

## Статистика площадок

Раздел «Статистика» принимает выгрузку из Студии Дзена или vc.ru — CSV или XLSX. Система
сама находит нужные колонки и раскладывает строки по статьям: по ссылке на публикацию, а
если её нет — по заголовку. Сначала загрузите с галочкой «только посмотреть»: увидите, что
получится, и при необходимости поправите сопоставление колонок.

Цифры можно вводить и руками — на странице статьи. Каждый ввод сохраняется срезом за день,
поэтому виден прирост между неделями.

## Дашборд

Раздел «Дашборд» показывает воронку: показы → дочитывания → переходы → подписки → заявки →
продажи, с конверсией на каждом шаге и выручкой на статью. Там же вносятся заявки и продажи:
достаточно указать Telegram-username — система сама поймёт, какая статья привела человека.

Статьи-лидеры автоматически становятся образцом для генератора: их тексты уходят в промпт
как примеры. Можно назначить эталон и вручную — кнопкой на странице статьи.

## Фоновые задачи

```bash
./.venv/bin/python -m app.scheduler.runner     # добор меток раз в сутки, напоминание раз в неделю
./.venv/bin/python -m app.cli metrics-reminder # проверить свежесть статистики прямо сейчас
```

Если задать `NOTIFY_CHAT_ID`, напоминание «пора обновить статистику» придёт в Telegram.
В контейнерах: `docker compose --profile tracking up -d bot scheduler`.

Без `ANTHROPIC_API_KEY` система работает на шаблоне-фолбэке: тексты собираются из контент-ДНК
без обращения к модели. Удобно для демонстрации, но для боевых текстов нужен ключ.

## Тесты

```bash
./.venv/bin/python -m pytest tests -q
```

Веб-тесты и тест миграций используют отдельную базу `traff_test` на том же Postgres;
если он не поднят, эти тесты пропускаются, а тесты ядра всё равно проходят.

## Документация

- `CLAUDE.md` — карта проекта, конвенции, грабли.
- `DEPLOY.md` — развёртывание на сервере, обновления, бэкапы.
- `WORK_LOG.md` — решения, разбор правок заказчика, статус этапов, открытые вопросы.
- `_local_docs/` — приватная рабочая вики (не в git): доступы, архитектура трекинга,
  открытые вопросы, отчёты по сессиям.
